# Contributing

- Keep World Radar free for everyone. Do not add subscriptions, billing, paid tiers, paywalls, or premium entitlements.
- Add translation keys in all nine locale files in the same pull request.
- Test Arabic and Hebrew in RTL and all other locales in LTR.
- Use CSS logical properties for directional layout.
- Do not commit secrets or private feed credentials.
- New news-source adapters must document licensing, attribution, rate limits, and failure behavior.
- AI output must cite stored source records and expose its limitations.
- Do not enable paid providers or paid infrastructure without explicit owner approval.
